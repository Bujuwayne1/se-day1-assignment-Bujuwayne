#Part 1: Introduction to Software Engineering

Explain what software engineering is and discuss its importance in the technology industry.
Software engineering is a structered use of engineering principles,techniques and tools to create and maintain reliable software. It covers the whole process from designing and building to testing launching and also updating. Software Engineering is important in the tech industry driving the development of applications and systems that support communication business and healthcare.

Identify and describe at least three key milestones in the evolution of software engineering.
1.The Beginning of programming (1940's)-early machines like ENIAC were programmed manually using machine language and punch cards.
2.Introduction to high level languages(1950's)-programming languages became more user friendly with the development of languages like fortran and cobal
3.Structured Programming and Development Models(1970's)-this reduced reliance on goto statements and the waterfall model was introduced for systematic software development

List and briefly explain the phases of the Software Development Life Cycle.
1.Requirements-Gathering and documenting user needs and system requirements
2.Design-Create high-level system designs of the software architecture and user interface
3.Implimentation- Writing code and building the software according to design specifications
4.Testing-Conducting various tests to ensure software meets quality standards and functional requirements
5.Deployment- Releasing software to users and customers
6.Maintanance-Providing ongoing support,updates, and enhancements to software after development

Compare and contrast the Waterfall and Agile methodologies. Provide examples of scenarios where each would be appropriate.
1.Waterfall takes a sequential approach,while agile takes an iterative approach- Waterfall could be used for developments that have a straight approach while agile could be used for projects that require continuous development
2.In waterfall changes are hard to implement while in agile changes and development are easy to implement-waterfall methodology could be used to develop banking systems and government projects while agile methodology could be used for mobile app development and web services

Describe the roles and responsibilities of a Software Developer, a Quality Assurance Engineer, and a Project Manager in a software engineering team.
1.Software developer-one who writes code and implements software solutions
2.Quality assurance engineer-ensures software quality through constant tests
3.Project Manager-oversees planning,execution, and delivery of software projects
4.System Architect-designs the structure and architecture of software systems
5.UI/UX designer-creates user interface and software experience for software application

Discuss the importance of Integrated Development Environments (IDEs) and Version Control Systems (VCS) in the software development process. Give examples of each.
Intergrated development systems provide the needed tools for writing,debugging and testing code eg visual studio code. it is important because it speeds up coding with its intelligent suggestions,simplifies debugging and testing,streamlines workflow by creating multiple development tools.
Version Control System-allows developers to make changes to source code and coordinating work among the members. A good example is git which is usually paired with platforms like github. it is important because it enables team collaboration by tracking contribution,prevents data loss with version history and rollback features,facilitates parallel  development by allowing multiple branches.

What are some common challenges faced by software engineers? Provide strategies to overcome these challenges.
1.Changing requirements-requirements may change during projects which may cause delay
2.Tight deadline-pressure to deliver project on schedule may lead to rushed development and compromised quality
3.Technical debt-this are accrued from shortcuts and low quality solutions,this can hinder technical developments and increase maintainance costs

Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance.
1.Unit testing-focuses on testing individual software components,ensures that each unit functions as expected before intergration,it is important because it identifies bugs early in development.
2.intergration testing-tests how different components and modules work together also ensures proper communication between systems such as databases
3.System testing-evaluates entire software application to ensure it meets system requirements,involves functional and non functional testing
4.Acceptance testing-determines wether software meets user specification and business requirements,always conducted by end users or stakeholders as user acceptance testing (UAT).

Define prompt engineering and discuss its importance in interacting with AI models.
Prompt engineering is the practise of crafting effective inputs(prompts)to guide ai models in generating accurate and relevant responses, it ivolves structuring queries in a way that optimises the models output.It is important because it enhances accuracy and relevance of ai generated response, it also improves interaction by refining ai responses.

Provide an example of a vague prompt and then improve it by making it clear, specific, and concise. Explain why the improved prompt is more effective.
vague prompt: tell me about cars.Improved prompt: "Explain the key differences between electric and gasoline cars, including their efficiency, costs, and environmental impact.".
The improved prompt is effective because its more specific,has clear expectations and finally it is concise but detailed.
